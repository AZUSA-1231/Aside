# Aside v1 实机验收表

更新：2026-11-08。状态：**统一实机默认延期，未执行。** 本表按 [V1-SCOPE](./V1-SCOPE.md) 的建议冻结稿补充候选 R1 项；范围仍待用户确认，不因此宣称新增功能已实现。

运行方式：在真实 Windows 桌面上逐项执行，记录**实际观察**，不写"通过"。不符合预期即记为发现，先登记到本表下方"发现的缺陷"，再决定是否阻塞 v1。任何一项不得因为自动测试通过而跳过。

执行时机：功能开发阶段不反复要求整套实机；各功能自动回归照常。开发收口后、公开发布前集中执行当前 R1 项。旧 F1–F8 保留为历史草案，**不是当前建议 R1 的阻断条件**；新增 F9–F14 / H / I / J 均尚未执行。

**证据纪律**：不记录 API key、文档正文、MCP 原始帧或模型原始响应。只记录形状与结果（例如"显示 3 个工具名"而非工具定义全文）。
