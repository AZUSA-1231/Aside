# Cycle 7 版本 B：透明窗口上的透光板 / 分岛

> 以下是版本 B 初始视觉改动的历史记录，行号和“未运行检查”指当时的改动。
> 后续快捷键隐藏、胶囊删除和接口修正的当前证据见 [FRONTEND-REVIEW.md](../FRONTEND-REVIEW.md)。

**工作版本：** 基于 `cycle-7-acrylic-v1` 的下一版。前端样式集中在 `src/plate.css`，它在 `src/App.tsx` 中排在 `App.css` 后加载；下面行号指本次新文件。

## 视觉目标与物理边界

- Tauri 仍是透明、无边框窗口，但移除 `windowEffects` 和整窗系统阴影：参见 `src-tauri/tauri.conf.json:21-28`。这是**唯一的窗口外观配置变化**，没有改 Rust、runtime、IPC。
- `src/plate.css:32-44` 让整窗 HTML 容器完全透明。顶部控制、捕获/上下文、对话、权限/附件、输入分别有自身的背景、边缘和阴影；岛与岛之间不绘制颜色，能直接看见桌面。
- **此版是“透光板材质”，不是原生 Acrylic。** 背景图标会被染淡，但不会真正失焦。`App.css` 中 JSON 预览遮罩仍可 `backdrop-filter` 模糊**网页内部**内容，不能把桌面模糊。
- “稍微缩小尺寸”指视觉岛群而不是原生窗口：对话卡限定高度并内部滚动，整个岛群纵向居中，四周留出透明空间。窗口仍占原有侧栏范围，**透明空隙目前可能拦截鼠标点击**；纯 CSS `pointer-events` 不等于对 Windows 桌面穿透。

## 最值得先调的变量（`src/plate.css:6-28`）

| 变量 | 作用 | 现在的值 |
| --- | --- | --- |
| `--plate-top` / `--plate-bottom` | 对话、顶部和附件岛的上亮下冷渐变；alpha 越低桌面越明显。 | `.93` / `.87` |
| `--plate-soft` | Context 和捕获小岛的半透明底。 | `.84` |
| `--plate-edge` | 独立岛的白色轮廓；过亮会出现白边。 | `.68` |
| `--plate-radius` | 对话主岛的大圆角。 | `28px` |
| `--plate-gap` | 岛间透明间隙。 | `12px` |
| `--plate-shadow` | 大卡投影和上缘内高光。 | `18px / 42px` 外投影 + `1px` 内高光 |
| `--plate-small-shadow` | 顶部、Context、捕获、权限和胶囊的小投影。 | `8px / 22px` 外投影 + 内高光 |
| `--plate-button` / `--plate-button-hover` | 近黑实色主按钮及 hover。 | `#292d39` / `#3d4351` |
| `--plate-button-depth` | 按钮厚度：顶面高光、底缘暗线、小投影。 | `1px` 高光 / `2px` 暗线 / `3px 7px` 投影 |
| `--plate-focus-glow` | **唯一刻意设置的淡蓝色焦点光晕**；输入框获得焦点时出现。 | `3px` 外环，alpha `.16` |

若想让图标不干扰阅读，**先提高** `--plate-top`/`--plate-bottom` 的 alpha；若觉得卡片太实，逐步降低 alpha，但不会因此产生真正模糊。桌面背景极端复杂时，阅读岛应比捕获小岛更不透明。

**阴影/高光/发光不是一件事：** `--plate-shadow` 抬起大卡，`--plate-small-shadow` 托起小岛；两者的 `inset` 是边缘高光。只有 `--plate-focus-glow` 是独立的焦点光晕。不要通过给整个透明窗口添加背景来调卡片投影，否则透明间隙会重新变成一块矩形。

## 当前实现范围

本版只实现视觉分岛和阅读区域的布局缩小，未增加“点击透明间隙穿透到桌面”的原生命中测试，也没有真实桌面模糊。按用户决定，**测试、构建及人工验收尚未由本轮执行**；请以实际桌面场景决定是否继续调整。
