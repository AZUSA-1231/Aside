### 7.3 “完成”的适用范围

R4 **当前有界开发清单完成**，不等于产品级 runtime 完全齐备、Cycle 5/6/7 整轮验收或已发布。FE-08 / R1 的真实窗口切换、80/20 恢复、Acrylic / DWM / DPI 观察尚无本轮桌面证据；真实 provider、第三方 MCP、真实文档人工任务和完整可读性验收仍未执行并按既有决定延期。安装包、Node 打包、干净环境与发布也继续延期。

G01 的同步加载 / 单次解析没有普遍硬时限；Word 列表类型读取、无 OCR、单一会话、文件配置重启加载等限制明确保留。MCP 摘要识别的是已接受的输入 schema 和启动配置，不证明服务实现不变或进程被沙箱化；每次调用仍需独立决定。所有旧自动结果只对各自记录的工作区成立，R2/R3 摘要不回写为 R4 的源码值。
