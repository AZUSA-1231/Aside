# P2：默认目录与产物

日期：2026-11-01。状态：待执行，依赖 P0，配合 P1 设置入口。批次：C8.1。问题见 [ISSUES.md](../ISSUES.md)。

## 范围与用户结果

没有手选目录时，用户仍能得到实际落盘且可定位的产物；原文件不被隐式搬动。默认目录只提供基础落点，不实施 memory、自组织或自动清理。

## 计划

1. 原生层用系统文档目录 API 提供默认路径，在设置中允许更改和定位；应用配置不提前创建用户文件。
2. 明确显式 workspace、捕获来源、默认根的优先级；任务启动时固定来源及输出范围。
3. 衔接外部来源文档与默认产物位置，复用现有工具、版本检查、预览 / 审批 / 验证；不放大到共同上级目录、不改 cwd、不静默复制原件。
4. 在结果中展示实际产物路径，支持打开所在目录；处理不可写、不存在及被移除等情况。
5. 回归捕获、文件读写与会话切换时的范围隔离。

## 验收边界

无 workspace 可写出产物；外部来源只在明确范围内读取，默认输出不覆盖原件，删除会话不删产物。应用设置 / 凭据 / 日志 / 会话目录不会因默认根解析被意外暴露。

验证包括路径解析、跨根边界、权限 / 竞态、结果定位与前端路径展示。现有单 workspace 不能未经修改就宣称实现跨根输出；这是必须解决的 C8-I003。
