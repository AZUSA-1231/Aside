# P2：默认目录与产物

日期：2026-11-01。状态：开发与自动验证完成，P0/P1 已提交为 `b5a0bd1`，P2 留在工作区。批次：C8.1。问题见 [ISSUES.md](../ISSUES.md)。

## 范围与用户结果

没有手选目录时，用户仍能得到实际落盘且可定位的产物；原文件不被隐式搬动。默认目录只提供基础落点，不实施 memory、自组织或自动清理。

## 计划

1. 原生层用系统文档目录 API 提供默认路径，在设置中允许更改和定位；应用配置不提前创建用户文件。
2. 明确显式 workspace、捕获来源、默认根的优先级；任务启动时固定来源及输出范围。
3. 衔接外部来源文档与默认产物位置，复用现有工具、版本检查、预览 / 审批 / 验证；不放大到共同上级目录、不改 cwd、不静默复制原件。
4. 在结果中展示实际产物路径，支持打开所在目录；处理不可写、不存在及被移除等情况。
5. 回归捕获、文件读写与会话切换时的范围隔离。

## 验收边界

无 workspace 可写出产物；外部来源只在明确范围内读取，默认输出不覆盖原件，删除会话不删产物。应用设置 / 凭据 / 日志 / 会话目录不会因默认根解析被意外暴露。

验证包括路径解析、跨根边界、权限 / 竞态、结果定位与前端路径展示。现有单 workspace 不能未经修改就宣称实现跨根输出；这是必须解决的 C8-I003。

## 本批实现决策

- 原生层通过 Tauri `PathResolver::document_dir()` 得到系统文档目录，建议根为其下的 `Aside`；通过子进程环境传给独立设置服务和 runtime，两者使用同一有效快照。不拼接用户主目录猜测 Documents。
- 有默认根时，手动选择的任务 workspace 优先作为可写输出范围，否则使用配置的默认根。新捕获单独形成只读来源：文件捕获只开放该文件，目录捕获只开放该目录；不取共同上级。来源用绝对路径寻址，相对路径始终指向输出根。
- 任务启动时固定输出和来源；仅同一会话的连续任务可重用仍有效的来源。应用新设置后重新解析默认根，不沿用旧默认输出。未收到原生建议路径的独立 Node 调用保留旧的显式 workspace 行为。
- 默认根可不存在，读取设置、启动会话、预览和拒绝审批均不创建目录；首次获批写入时验证已有父目录并创建根，再走现有版本检查与原子写入。已存在的根被移除或重定向时不得自动改用其他目录。
- 默认根不得包含或落入应用配置、会话等私有位置；检查规范路径与链接。历史继续存放在原位置。结果保留实际绝对路径，界面提供定位；缺失目录定位报可恢复错误，不以定位为由创建文件。
- 本批只增加基础目录设置与现有 activity 中的来源 / 输出说明，不扩展前端布局、memory、自动清理或第三方 agent。
- 目录来源与显式输出可以重叠；来源的读取范围不授予输出之外的写入能力，单独捕获的文件即使在输出内仍只读。显式切换输出目录保留同一会话的有效来源。

## 保留限制与下一步

- 产物根不是自动清理的缓存，不迁移或删除已有源文件、历史或输出。首次批准后若后续写入失败，可能保留已创建的空目录；不自动回滚用户目录。
- 默认根下的新文件可直接创建；更深层的输出父目录需要已存在，没有增加通用 mkdir 工具。保留现有路径 / 原子提交机制，不宣称抵御任意外部进程的所有目录替换竞态。
- 原生 Documents 解析已接源码及子进程环境回归；重定向 Documents、真实快捷键 / Acrylic / Explorer 定位、真实 Word 打开和厂商模型请求尚未联合人工验收。安装包和历史整轮人工延期保持原状态。会话列表 / GUI 删除属于 P4，本批只验证存储分离，不声称已实现会话管理。
