# P4：会话管理

日期：2026-11-01。状态：待执行，依赖 P0 与 P1 的安全 runtime 生命周期。批次：C8.2。问题见 [ISSUES.md](../ISSUES.md)。

## 范围与用户结果

复用现有 JSONL 会话，提供新建、列表、命名、指定恢复 / 切换和删除；重启后可找回。会话目录可见、可打开，保留 ASIDE_SESSION_ROOT，不做历史根自动迁移。

## 计划

1. 给现有 repository 增加 Aside 所需的列表、选择与名字元数据，校验身份并兼容旧会话。
2. 将新建 / 切换作为空闲状态下的显式操作；任务运行时先停止并完成保存，不丢未完成状态或接收旧 generation 的事件。
3. 为历史恢复和删除定义确定的权限 / workspace / capture 清理规则；记录不授予旧权限。
4. 提供轻量历史列表及重命名 / 删除操作；删除仅作用于选定历史，不移动或清理来源和产物。
5. 覆盖持久化失败、损坏会话、快速切换、重启恢复与跨会话隔离。

## 验收边界

至少两个命名会话可反复切换且重启后仍可找回；同一时刻只有一个活动会话。失败不能切到半完成状态；历史文本恢复不等于恢复桌面快照。全文检索、导出、分支与并行任务以后单列。
