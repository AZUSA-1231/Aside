## 1. 用户结果与停止线

重开一个做过文件任务的会话，能看到「哪次执行产出了哪个文件」，并直接打开它或所在文件夹。文件后来被移动或删除时，界面明确说打不开，而不是给一个点了没反应或假装成功的按钮。

停止线：F9 的自动可验证部分成立——两个独立文件任务后重开，产物与各自执行正确对应、可定位；失效路径有明确反馈；历史不串会话。不新建任务管理系统，不做产物版本 / 快照 / 内容预览。

根因单一：产物引用存在于运行期事件里，但没有进入恢复投影。

## 3. 输入 / 输出与契约

**输入**：已存的 `toolResult` 消息里的 `details`。不新增持久化字段。

**输出**：恢复出的工具调用可携带一个可选的产物描述；界面据此提供与运行期**同一套**产物事实与定位入口。

**单一投影，不是两份逻辑。** 运行期已经从 `details` 经 `writeDocumentStatus` 得到「操作类型、绝对路径、字节、结构、是否重新打开、来源路径与保真警告」。恢复侧必须复用这个函数，而不是只挑一个路径字符串：否则同一份记录在实时和恢复后会得出不同的事实（实时知道"Transformed、已重新打开、源可能丢列表类型"，恢复后只剩路径）。因此：

- `writeDocumentStatus` 增加一个参数，用于要求路径必须是绝对路径；实时调用保持现状，恢复调用要求绝对。函数仍是「什么算产物、产物包含哪些字段」的唯一定义。
- 恢复侧从 `details` **白名单提取**这些字段（不整包透传，避免把无关内容带进事件），满足条件时作为产物描述挂到调用上。

提取规则（最小、不猜）：

- 产物路径只取 `output_absolute_path`；相对 `output_path` 永不用作定位目标。工作区不持久化，重开后它无法解析，把它当绝对路径会落到进程当前目录，那是错误的成功。
- 只在调用状态为成功（`succeeded` / `partial`）时提取。失败结果里的路径不是产物，给按钮等于宣称一个没发生的产出。
- 绝对路径且不含控制字符，长度设上限。不合规就当作「未记录产物」，不显示定位入口。
- 一次调用最多一个产物描述；多个写入各自携带自己的。
- `details` 因截断而无法解析时不推断。

定位：复用 `reveal_existing_path`。失败时把 `path_unavailable` 如实显示（「文件已移动或删除」），不静默、不重试、不搜索同目录同名文件。

不做：不新建任务 / 产物管理实体，不建立产物索引，不做内容预览、版本历史、去重、目录同步；**不改运行期产物卡的视觉与字段**（只让它与恢复共用同一个投影函数）；不改写工作区恢复行为。

## 4. 分步实施，串行完成

1. **统一投影**：把 `writeDocumentStatus` 改成可要求绝对路径的共享函数；实时路径行为不变。
2. **恢复侧提取**：`restoreToolCalls` 按白名单提取产物字段并挂在调用上；不改变已有的状态 / 来源 / 截断语义。
3. **契约字段**：`RuntimeHistoryToolCall` 增加可选产物描述；旧数据缺省时一切照旧。
4. **界面投影**：恢复调用列表用同一函数渲染产物事实并提供「在文件夹中显示」；失败显示明确错误。
5. **回归与证据**：成功、失败、相对路径、截断、失效路径、多产物、旧会话兼容、实时与恢复字段一致。

## 5. 失败语义

- 文件已被移动或删除：显示「文件已移动或删除」，不重试、不搜索同目录同名文件、不把路径改成别的。
- `details` 缺路径或不可解析：不显示定位入口，界面不声称有产物。
- 相对路径或非绝对路径：同上，视为未记录。
- 失败调用的结果里带路径：不当作产物。
- 定位命令本身失败（权限、资源管理器异常）：如实显示，不影响会话其它状态。
- 恢复仍是只读：不因提取产物而写回会话文件。

## 6. 自动完成条件

| 检查 | 必须证明 |
| --- | --- |
| 产物关联 | 两次独立写入后重开，两个调用各自对应正确产物，不串到另一条 |
| 单一投影 | 同一份 `details` 经实时与恢复两条路径得到相同的产物事实；不存在只取路径的第二份实现 |
| 只认绝对路径 | `output_absolute_path` 被采用；只有 `output_path` 时不显示定位入口 |
| 状态门槛 | 成功调用有产物；失败调用即使 `details` 含路径也不显示 |
| 有界 | 超长 / 含控制字符的路径被拒绝；`details` 截断时不推断 |
| 失效反馈 | 路径不存在时定位失败信息可读，不伪装成功 |
| 兼容 | 无 `details` 的旧会话恢复如常，不报错 |
| 白名单维护 | 文档写明：新增产物字段必须同步白名单，否则恢复视图会静默少一项 |
| 只读 | 重开前后会话文件逐字节不变 |
