# Chromium UIA Samples

These files are generated by
[sample-chromium-uia-fixtures.ps1](../../../tools/sample-chromium-uia-fixtures.ps1)
from the synthetic pages under `tools/fixtures`.

Each successful run creates one directory per fixture containing:

- `uia-control-view.json`
- `uia-content-view.json`

The sampler uses a disposable browser profile and accepts only a visible
Chromium main window. Use `-IncludeContent` only with the synthetic fixtures;
the probe's default mode stores lengths and hashes instead of page content.

The current non-interactive execution session could not produce valid browser
trees. Do not add samples from a personal page to this directory.
